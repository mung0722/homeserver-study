## Part B. 코딩 문제 -> `q*.py`의 `# TODO` 채우기

### B1. `q1_dates.py` - 한국어 날짜 해석기

1. 예외 클래스 `DateFormatError` (Exception 상속)
2. `parse_korean_date(text)`
    - `"2026년 11월 07일 23시 59분"` -> `"2026-11-07T23:59:00+09:00"` (24시간제, 한국 시간)
    - 앞뒤 공백은 무시한다.
    - 형식이 맞지 않으면(파이썬이 `ValueError`를 내면) -> `DateFormatError`로 **바꿔서** 던진다.
        - 메시지에 **공백을 제거한 원래 글자**를 포함한다.
        - 원래 `ValueError`를 **원인(cause)으로 연결**한다.
3. `is_overdue(due_iso, now)`
    - `due_iso`: ISO 문자열 (예: `"2026-11-07T23:59:00+09:00"`)
    - `now`: 시간대가 붙은 `datetime`
    - `now`가 마감보다 **늦으면** `True`. **정확히 같은 시각은 아직 마감 전**(`False`)

### B2. `q2_keys.py` - 키 만들기와 중복 제거

1. `make_key(item, fields)`
    - `fields`에 적힌 순서대로 `item`의 값을 꺼내 `"|"`로 이어 붙이고, SHA-256 16진수 문자열을 돌려준다.
    - `fields`에 있는 이름이 `item`에 없으면 `KeyError`가 나면 된다 (따로 처리하지 않아도 됨)
2. `find_new(items, existing, fields)`
    - `existing`: 이미 등록된 키들의 `set`
    - `items` 중 **아직 등록되지 않은 것만** 원래 순서대로 리스트로 돌려준다.
    - 같은 목록 안에 같은 키가 여러 번 나오면 **처음 것만** 남긴다.
    - 넘겨받은 `existing`을 **수정하면 안 된다.**

> 새 도구 4개
> - `datetime.fromisoformat("2026-11-07T23:59:00+09:00")` -> ISO 글자를 날짜 객체로 (`isoformat`의 반대)
> - 시간대가 붙은 날짜끼리는 `<`, `>`, `==`로 비교할 수 있다. 시간대가 달라도 **같은 순간**인지로 비교한다.
> - `raise 새예외("...") from 원래예외` -> 새 예외를 던지면서 "원인은 이거였다"는 기록을 남긴다.
> - `set(기존set)` -> set을 **복사**한다. 복사본에 `.add()`해도 원본은 그대로다.
